# DocShot Post-V1 Backlog

This document tracks scheduled, small post-V1 milestones. None of these features belongs in
the V1 screenshot scope, and each must be designed, approved, implemented, and verified on its
own rather than bundled into one release.

---

## Candidate Post-V1 Features

1. **Screen Recording (first recording milestone)**: Record a selected window or region locally. Export MP4 first. Audio defaults to Off, with System Audio, Microphone, and Both selectable only when available and permitted. A GIF is allowed only for a clip of 15 seconds or less and under a clearly labelled, yet-to-be-finalised file-size guard; GIF contains no audio. Recording must use explicit output and never create history, cloud uploads, accounts, or analytics.
2. **Long / Scrolling Screenshot**: Capture scrolling viewports across long web pages and documents by automatically stitching vertical frames.
3. **On-Screen OCR**: Extract selectable text from any captured region or window using Vision framework, local-only and after a privacy review.
4. **Screen Ruler & Pixel Dimension Overlay**: Live pixel distance and aspect ratio measurements while inspecting elements.
5. **Desktop Unclutter / Clean Backdrop**: Temporarily hide desktop icons during capture sessions, with a safe reversible restore mechanism.
6. **Overlay & Reference Images (Pin to Screen)**: Float captured screenshots on top of all windows as borderless reference overlays.
7. **Combine & Stitch Screenshots**: Merge multiple screenshots vertically or horizontally into a single canvas.
8. **Bendable & Curved Arrows**: Multi-point bezier curve annotations for pointing around complex UI structures.
